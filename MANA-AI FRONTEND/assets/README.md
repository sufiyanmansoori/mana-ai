# Flutter app assets

Place licensed product images, icons, and fonts in dedicated subdirectories
here and declare only populated asset directories in `pubspec.yaml`. Record
the source, license, and attribution of every bundled third-party asset.

Current bundled assets:

- `logos/mana_ai_logo.svg` — app mark and splash branding
- `images/ai_hero.svg` — hero illustration for onboarding or landing screens
- `icons/chat.svg`, `icons/mic.svg`, `icons/send.svg` — core chat actions

These files are intentionally designed as lightweight SVG placeholders so the
app can start consuming assets without depending on third-party image packs.
